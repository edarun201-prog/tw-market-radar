完成後的樣子

先看大盤，再看雷達抓到什麼

網站已經完成，執行 python -m radar web 就能在本機打開。閱讀順序固定：今日市場 → 今日雷達（先看分類和數量，點開才看股票）→ 個股「為什麼被雷達注意」→ 詳細資料。打開先是一頁全螢幕影片背景的入口頁（點陣字標題、當日數字跳動），進去之後的每一頁都是同一套黑底、白色膠囊導覽的風格。有新手、標準、進階三種模式，名詞都有「是什麼／代表什麼／不代表什麼」的說明；網頁是多頁式的：今日市場、今日雷達、搜尋、個股、說明各是一頁，傳出去的 HTML 檔也一樣；也是響應式的：桌面、平板、手機同一份功能，只是導覽的位置不同；手機上還可以安裝成 App、離線看過的頁面。這裡的數字與股名是示意；實際網站用的是資料庫裡的真實盤後資料。台股慣例紅漲綠跌，不分多空的訊號用藍色。

作品重點

十二個設計決策

這一段是作品集裡最能說明工程能力的部分。每一項都對應到程式裡實際的位置。

重跑同一天，結果完全一樣

repository.py · write_market_day

所有寫入都是 upsert。重跑時，這次被驗證剔除的列也會從資料庫刪掉，資料庫永遠跟最後一次成功的來源一致。

原始回應先存檔，再解析

raw_store.py · reprocess

每次回應存成 data/raw/{來源}/{資料集}/{日期}.json.gz。解析規則改了，用 reprocess 從檔案重算一年資料，不必再打證交所。

兩層驗證：整批擋下或逐列剔除

validators.py

行情少於 800 筆，或和前一交易日差超過 20%，整批不寫入。高低價矛盾的個別列剔除並記警告；剔除超過 1% 也整批失敗。

分清楚「還沒公布」和「休市」

ingest.py · final 參數

18:30 起每 20 分鐘重試到 21:30。中間查無資料記為 pending，最後一次仍查無才判定休市。交易日曆由抓取結果自動建立，所以 2026-07-10 巴威颱風臨時休市這種不在任何假日表裡的日子，也會正確記錄。

回補一年，可隨時中斷

backfill.py · ingestion_runs

約 500 次請求、間隔 4 秒加隨機抖動。已成功的日期自動跳過，中斷後重跑同一行指令就會接著做。worker 啟動時也會補抓漏掉的日子。

換資料來源只動一層

adapters/base.py · Protocol

只有 adapter 知道資料從哪來。之後加上櫃（TPEX）或 FinMind 備援，只要實作同一個介面加一支 normalizer，驗證與入庫都不用改。

還原價：除權息表＋從官方漲跌反推

features.py

除權息用 TWT49U 的參考價 ÷ 前收盤；TWT49U 不含的減資、分割，從「收盤 − 官方漲跌 ≠ 前一日收盤」反推。一年 32 萬筆個股日資料（243 個交易日 × 約 1,350 檔）的還原報酬與官方漲跌幅全部一致，颱風休市順延的除權息也落在正確的日子。

訊號有冷卻期，AI 只能引用證據

signals.py · summary.py

同一檔的同類訊號在冷卻期內不重複，每天從 136 則降到 46 則。每筆訊號都存判斷依據；AI 摘要只看得到這些數字，寫入前逐一檢查數字出處與買賣建議用語，不符就不存。

多頁式，桌面與手機同一份功能

base.html · navitems · export.html

今日市場、今日雷達、搜尋、個股、說明各是一頁。網站是一般的多頁網址；要傳的 HTML 檔也是多頁：同一個檔案裡用 #v-radar、#s-2330 切換，一次只顯示一頁。換頁與新手／標準切換只用 HTML 與 CSS（:target、:has），因為 iPhone／iPad 從 LINE、「檔案」預覽時不執行 JavaScript；能執行時才另外加上搜尋與還原捲動位置。導覽項目只寫一次，桌面在上方、手機在底部，測試檢查兩邊完全相同。

過去的快照只看得到那一天

export.py · stock_context(as_of)

匯出過去的日子時，個股的行情、訊號、法人與除權息都只查到那天為止。這是檢查 07/29 檔案時發現的錯誤：個股段落原本顯示最新一天的資料。修正後加了測試，並確認沒修正時測試會失敗。回測也一樣：快照只用那天之前已經知道結果的訊號。

回測和全部股票比，而且看中位數

outcomes.py · explain.backtest_verdict

這一年指數大漲，和指數比會讓每種訊號都「很準」；所以基準是同一天全部股票。個股報酬偏向少數大漲，平均會被拉高，判斷用上漲比例加中位數；另外算隔天才買與扣成本，說明文字全部由數字依規則產生。

入口頁與內頁同一套視覺

style.css · .landing · lp-

入口頁照規格做全螢幕影片、點陣字與數字跳動；類別與變數都加前綴，不會和內頁互相影響。內頁改用同一組顏色與元件（白色膠囊導覽、深色膠囊、發光按鈕），台股紅漲綠跌保留。沒有 JavaScript 時換頁、選單、模式切換照樣能用。

Step 11 · 訊號回測（Phase 3）

市面說法 vs 資料：沒有那麼簡單

每一筆訊號出現之後 5、20、60 個交易日，股價實際怎麼走（已還原除權息），和同一天「全部上市股票」比較，而不是和加權指數比。 也算「盤後才看到、隔天才買到」的差別，以及扣掉手續費與證交稅（約 0.585%）之後的上漲比例。資料：2025-09-24～2026-08-31 出現、已滿 20 個交易日的 9,869 筆 v2 訊號。

「大盤一直漲，買什麼都會漲。」

同期加權指數 26,197 → 47,940（+83%），但任選一天買進全部上市股票，20 個交易日後平均只有 49% 上漲、中位數 −0.3%。指數被少數大型股帶動。

「外資連續買超，股價就會跟著漲。」

連買之後 20 日：52% 上漲、中位數 +0.4%；連賣之後反而是 55%、+1.1%。扣掉交易成本，連買的上漲比例從 52% 降到 49%。

「短線急漲的強勢股，會繼續漲。」

平均 +5.1% 是被少數飆股拉高的；中位數 −0.7%，中間一半的結果落在 −11.3% 到 +16.0%。

「爆量代表主力進場，接下來會漲。」

之後 20 日只有 46% 上漲，比同一天全部股票的 49% 還低；中位數 −1.1%。

網站分三種深度：新手看每種訊號一句話（例如「之後比全部股票好一些」），標準看一張表，進階看完整分布、隔天才買、扣成本，以及這些「市面說法 vs 資料」和回測的限制（只有約一年、同一種盤勢、訊號重疊、漲跌停買不到）。全部只描述過去，不代表之後。

執行環境

在一台 4 GB 的 ThinkPad X240 上跑完整系統

開發與日常執行都在同一台 2014 年的筆電上。記憶體是唯一的瓶頸，所以每一層都選最省的做法。資料一天只變一次，這點讓省資源變得容易。

層做法平常占用
資料庫原生 PostgreSQL 18，不用 Docker（BIOS 沒開虛擬化，WSL 2 也要多吃 1–2 GB）；限制連線數、關閉 JIT、只接受本機連線≈ 60 MB（實測）
資料管線Windows 工作排程器每天 18:30 叫起 radar daily，跑完就結束、不開視窗；錯過的日子開機後自動補抓0（執行時最高 ≈ 75 MB，實測）
網站原規劃 Next.js，改成 FastAPI 直接產生 HTML，圖表在伺服器端畫成 SVG：沒有前端建置，和管線共用同一個環境；平常只傳匯出的 HTML 檔，網站不必開著≈ 85 MB（實測）
AI 解讀目前是模擬摘要；填入金鑰後用 Claude API（claude-opus-5）每天一次，估計 0.03～0.08 美元0

中 · 授權
公開上線前要確認證交所資訊使用規範

自己用沒問題；放上公開網站或作品集展示真實資料前，要先讀過規範，必要時只展示截圖或延遲資料。

中 · 上櫃歷史
上櫃只能從 2026-10-02 開始累積

櫃買中心 OpenAPI 只提供最新一天，網站的歷史查詢目前對程式沒有回應（不會去繞過人機驗證）。上櫃的訊號與回測要等資料累積；之後若歷史查詢能用，再一次補齊。

高 · 即時行情
上架讓別人看即時行情，需要先取得授權

盤中即時目前用證交所基本市況報導網站，只適合自己看。對外提供要先和證交所（上櫃另有櫃買中心）簽資訊使用契約，或改用已授權、可對外顯示的資訊廠商。程式已把資料來源做成可替換：拿到授權後新增一個資料來源類別、改一個設定即可。

中 · 封鎖
請求太頻繁會被暫時封鎖 IP

間隔已設 4 秒加抖動。回補期間不要同時手動 ingest，也不要調低 REQUEST_INTERVAL_SEC。

中 · 手機安裝
手機要安裝成 App 需要 HTTPS

瀏覽器只允許 HTTPS 或 localhost 的網站安裝與離線快取。這台電腦上可以直接安裝；手機要經過 HTTPS 連線或公開主機才行。目前給一個人看用 HTML 檔就夠，檔案本身也有手機分頁列。

低 · AI
目前是模擬摘要

沒有 Claude API 金鑰時，摘要依固定規則從當天數字組成，網站與匯出檔都標示「模擬」。在 .env 填入 ANTHROPIC_API_KEY 後自動改用 Claude。

本週要做

每天的成果：一個檔案

排程每天 18:30 跑完後，會把當天存成一個 HTML 檔，不需要網路或伺服器，雙擊就能開，可以直接用 LINE 或 Email 傳給要看的人。

1
data\exports\台股雷達_最新.html

每天自動更新，固定是最新交易日，直接傳這個檔就好；另外保留每一天的 台股雷達_YYYY-MM-DD.html。電腦、手機都能開：打開是入口頁，「看今天的盤後」進到今日市場；同一組導覽（今日市場、今日雷達、訊號回測、搜尋、說明），可以離線搜尋當天所有上市股票。

2
.\.venv\Scripts\python -m radar export --date 2026-07-29

想傳某一天（例如大跌那天）就指定日期匯出，不會動到「最新」。那天有 133 檔有訊號，最多收錄 80 檔的個股段落（約 5 MB），個股段落都停在那一天。

3
